COMO APLICAR
1) Baixe este ZIP para a raiz do projeto:
   C:\Projetos\casa-auto-pilot

2) Esteja na branch:
   rebuild/rainha-v1

3) Extraia:
   Expand-Archive .\casa-auto-pilot-rebuild-v2.zip -DestinationPath . -Force

4) Rode:
   npm.cmd run build
   npm.cmd run dev

5) Abra:
   http://localhost:8080/
